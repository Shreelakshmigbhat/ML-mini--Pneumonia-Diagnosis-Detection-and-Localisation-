## Bounding-box representation

There is one metadata row per image. For an image with one or more pneumonia boxes, each of `x`, `y`, `width`, and `height` is a JSON array stored in its CSV cell. Values at the same array index form one box, so multiple boxes are preserved without duplicating image rows or image files. Images without a box have `[]` in each coordinate cell and `bounding_box_available=false`; images with boxes have `bounding_box_available=true`.

The actual class values were read from `stage_2_detailed_class_info.csv`. The binary mapping is `Lung Opacity` → 1 and `Normal` → 0. Other class values are excluded.

## Reference-paper size check

The reference description expects 17,489 usable images after excluding Diseased/No Pneumonia. This local Stage 2 labeled cohort contains 14,863 usable images (-2,626 versus expected), so it does not match; the count was not adjusted to force a match. The local usable total is 6,012 Pneumonia + 8,851 Healthy, compared with the reference's 8,964 + 8,525. The local labels contain 11,821 excluded image IDs. The remaining 3,000 on-disk files are in the test folder and have no labels in the supplied CSVs, so they cannot be assigned to the binary cohort. Dataset release/filtering differences explain why the available labeled cohort cannot reproduce the reported 17,489 images from these files alone.
